## osp astrometry status

```text
usage: osp astrometry status [-h] --config CONFIG [--wait | --cancel |
                             --attach SUBMISSION_ID | --abandon]
                             job_id

positional arguments:
  job_id                Nova job number or OSP receipt ID

options:
  -h, --help            show this help message and exit
  --config CONFIG
  --wait                resume polling a saved receipt
  --cancel              cancel the local wait only
  --attach SUBMISSION_ID
                        attach a known Nova submission to an ambiguous receipt
  --abandon             retire an ambiguous receipt after checking Nova
                        history
```
