# N.I.N.A. calibration capture and camera characterization

**VERIFIED metadata**. QHYminiCam8M monochrome, camera ID matching the inventory, Full Resolution, gain setting 30, offset 30, binning 1×1, 3856 × 2180, USB limit 0, TOP-DOWN and 16-bit FITS output with BZERO=32768. Keep camera ID, driver/firmware and readout settings constant within each sequence. Preserve original headers. N.I.N.A. defines SET-TEMP as the set point and CCD-TEMP as the measured/driver-reported value. All supplied files report SET-TEMP=0 °C and actual CCD-TEMP near +19 °C. [N.I.N.A. header definitions](https://nighttime-imaging.eu/docs/develop/site/advanced/file_formats/fits/)

**UNVERIFIED temperature transfer**. Exact matching in the reported 0.1 °C bins is a conservative default, not a physical boundary. Equal cards are also not proof of equal real detector temperature, glow or bias. Never substitute the set point or edit FITS headers to force a match. The optional nonzero OSP tolerance requires recorded evidence. To validate a wider window, record stable measured-temperature groups bracketing the target, alternate or randomize acquisition order and use independent held-out groups. Quantify dark mean residual, repeatability, row/column patterns and hot-pixel/glow residual versus temperature separately by duration. Approve a window only when residuals fit a predetermined error budget for the actual science. [Astropy dark-current guide](https://www.astropy.org/ccd-reduction-and-photometry-guide/notebooks/03-01-Dark-current-The-ideal-case.html)

## Photon transfer, saturation and validation

UNVERIFIED measurement protocol. With stable illumination, sample 12–16 increasing levels from low unsaturated signal to clipping, spanning the linear region. Record at least 4 independent pairs per level and repeat the sequence on another run. For sky flats use fixed normalized illumination only if independently verified; an adjustable stable panel or laboratory source is preferable. Capture matched dark pairs at each duration and at least 30 minimum-exposure capped frames. Measure separately at the historical warm setting and any new stabilized set point. Interleave samples, document any measurement drift and inspect the full-resolution row/column behavior.

For a flat pair, subtract half the spatial variance of the dark-pair difference from half the variance of the flat-pair difference. Regress temporal variance against matched-dark-subtracted mean in the linear regime. The reciprocal slope gives electrons per stored ADU. Report uncertainty from independent pairs or sequences, keep quantization and correlations in the error budget, and identify the first range where measured response departs from the stated tolerance. Determine the raw clipping point and nonlinearity limit separately. The four-bit output code spacing matters. A conversion stated per native DN must be converted before use with stored ADU. The 65520 data pile-up identifies a practical defect candidate, not a calibrated saturation or linearity threshold.
